# voice-controlled-AI-robot
A Voice Controlled AI Robot using Python, Aurdino UNO ,and ESP32.It uses speech recognition to control robot movements and perform tasks through voice commands. The project focuses on AI, automation and IOT.
Voice Controlled AI Robot

Project Description

The Voice Controlled AI Robot is designed to perform robot movements using voice commands.

Objectives

- To control a robot using voice commands.
- To implement speech recognition.
- To perform forward, backward, left, right and stop operations.
- To develop an intelligent robotic system.

Technologies Used

- Python
- Arduino UNO
- ESP32
- Speech Recognition
- Artificial Intelligence
- IoT

Applications

- Smart Home Automation
- Personal Assistance
- Robotics
- Hands-free Control

Conclusion

This project provides an easy and smart way to control a robot using voice commands.
